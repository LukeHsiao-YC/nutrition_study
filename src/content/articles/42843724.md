### 重點摘要
本研究旨在評估美國2023年10月新引入的兒童腸道衰竭(IF)診斷碼(K90.83)的採用和利用趨勢，並探討其與醫療資源利用的關聯性。研究分析了2023年10月至2025年12月間PHIS資料庫中，來自48家醫院1,869名兒童的3,362次以K90.83編碼的住院就診記錄。結果顯示，該診斷碼的使用率每月線性增長2.6%，年增約36%，且腸道衰竭患者伴隨高比例的靜脈營養和導管相關血流感染。最終，研究指出兒童腸道衰竭導致顯著的住院併發症和高達12.1億美元的醫療費用，儘管診斷碼的採用度逐漸增加，但其不完全使用可能低估了實際疾病負擔。

### 研究縫隙 (Research Gap)
這篇文獻利用新引入的特定診斷碼(K90.83)，簡化了過往需仰賴複雜演算法才能識別腸道衰竭患者的困難，並首次描述了該診斷碼的初期採用趨勢及相關醫療負擔。然而，研究限制在於該診斷碼的採用率仍不完全，這可能導致實際的兒童腸道衰竭疾病負擔和流行率被低估。

### 原文資訊 (Original English)
**Title:** Adoption and Utilization Trends of a New Diagnosis Code for Pediatric Intestinal Failure: A multicenter retrospective cross-sectional database analysis.
**Abstract:** In October 2023, a new ICD-10-CM diagnosis code (K90.83) for intestinal failure (IF) was introduced in the United States. Previous studies have relied on complex algorithms to find intestinal failure patients in large databases. We aimed to characterize the use of the new diagnosis code for intestinal failure and its association with healthcare resource utilization. We conducted a retrospective multicenter cross-sectional study using the Pediatric Health Information System database from October 2023 through December 2025. Pediatric inpatient encounters coded with K90.83 were identified. Temporal trends in code utilization were assessed using hospital fixed-effects Poisson regression with robust standard errors clustered at the hospital level. Secondary analyses examined clinical characteristics and cumulative inpatient utilization among children who ever received an IF diagnosis code. We identified 3,362 IF-coded encounters from 1,869 children across 48 hospitals. Median age at first IF-coded encounter was 2.1 years. IF-coded encounters increased linearly by 2.6% per month (incidence rate ratio 1.026, 95% CI 1.012-1.040; p<0.001), corresponding to an approximate 36% annual increase, without a significant change in slope over time. Among IF-coded encounters, 86.9% included parenteral nutrition and 21.9% included CLABSI. Children who ever received an IF diagnosis code accounted for 25,144 inpatient encounters totaling 241,748 hospital days and more than $1.21 billion in standardized inpatient costs. Adoption of the IF diagnosis code has increased gradually. Although clinically coherent, incomplete adoption likely underestimates true disease burden. Even when identified solely by diagnosis code, pediatric IF is associated with substantial inpatient morbidity and cost.
